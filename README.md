# Lab wiki

국내 연구실의 공개 연구정보를 학교별로 모으는 위키다. 자료 수집과 근거 확인, 연구실별 자료 등록을 우선하며 드롭다운 탐색 등 UI 작업은 후속으로 진행한다.

## 등록 자료

- KAIST: [KAIST HCI Lab](wiki/kaist/hcil.md)

현재 한 개 연구실 후보의 부분 등록본이다. 기관 전체 조사나 모든 성과의 수집 완료를 뜻하지 않는다.

## 자료 읽기

각 항목은 공식 출처, 자료 확인일, 공개 자료의 표기와 미수집·미확인 상태를 함께 기록한다. 논문은 게시 연도와 정확한 게재일을 구분하고 이전 소속의 성과를 현재 랩 실적으로 합산하지 않는다. 교수·PI 한 명과 독립 연구실 한 개를 자동으로 등치하지 않는다.

첫 KAIST 조사 이력 구간은 2021-10-13–2026-10-13이다. 이후 원문 열람일은 별도로 표시한다.

내부 소싱 메모, 수집 원문 전체, 개인 연락처, 운영 로그와 시크릿은 이 저장소에 등록하지 않는다.
