## 자료 읽기

첫 KAIST 조사 이력 구간은 **2021-10-13–2026-10-13**이다. 연도만 있는2021·2026년 자료, 예정 성과, 날짜·소속 귀속이 불분명한 항목은 확정 실적 합계와 구분한다. 이후 원문 열람일은 별도로 표시한다. PI 이전 소속 성과를 현재 랩 성과로 자동 합산하지 않으며, 게시 명단의 이름·역할은 실제 재직 확인과 다르다.

각 항목은 공식 출처·자료 확인일·공개 자료의 표기와 미수집·미확인 상태를 함께 기록한다. 교수·PI 한 명과 독립 연구실 한 개를 자동으로 등치하지 않는다. 필드별 수집 상태와 독립 검토의 범위는 각 문서에 남긴다.

내부 소싱 메모, 수집 원문 전체, 개인 연락처, 운영 로그와 시크릿은 이 저장소에 등록하지 않는다.

이번에 추가한19후보 소개·상세38문서는 핵심 표기·자료구조·공개자료 경계와 선정 성과 표본의 제한 검토를 마쳤다. 전체 성과의 날짜·당시 저자소속·실제 재직 검증과 원문 접근 잔여는 남아 있다. 앞서 등록한5후보도 별도의 핵심·구조·선정 표본 제한 검토를 마쳤으며 DAIM·일부 성과 원문의 독립 접근 미검증은 남아 있다.
