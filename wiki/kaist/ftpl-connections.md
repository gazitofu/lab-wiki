# FTPL 공식 연결: 수송동력·다상유동 연구실

기계공학과의 배충식·황준식 두 교수에게 연결된 FTPL 홈페이지를 대조한 자료다. [랩 첫 화면](https://ftpl.kaist.ac.kr/)은 Future Transport Power Laboratory라는 명칭과 두 교수의 연락처를 함께 게시한다. 두 사람은 서로 다른 인물이며 이 문서가 두 기존 연구실 후보의 병합을 뜻하지 않는다.

학과 페이지는 실제 브라우저에서 각 이름을 클릭해 연구실명·홈페이지를 확인했다. 텍스트 추출기의 짧은 응답을 명단 부재로 해석하지 않았다. 현재 두 공식 확장행과 랩 두 교수 소개가 연결되므로 동일 URL만으로 오연결이라고 판정하지 않는다. 반대로 두 연구실의 별칭·공동운영·조직 개편 관계도 확정하지 않는다. 두 후보ID와 서로 다른 학과 표기명을 유지한다.

## 연구와 경력의 범위

랩 소개는 자동차·선박·항공 동력과 연소·분무·광학진단을 다루며, 황준식 학과 확장행은 고속 광학진단·난류·분무 미립화·추진 시스템을 적는다. [랩 Professors](https://ftpl.kaist.ac.kr/People)는 황준식의 KAIST 기계공학과 부교수 경력을2025년2월부터로 게시하고, Mississippi State University의2020년5월–2024년12월 경력도 별도로 적는다. 이전 기관 시기의 성과를 현재 KAIST 랩 실적으로 옮기지 않는다. 이 경력 표기는 실재직의 별도 검증이 아니다.
