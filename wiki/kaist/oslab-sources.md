## 이름·직위·위치와 정보 경계

제목은 누리집의 KAIST OS Lab과 Operating Systems Laboratory를 따른다. 학부 교수 소개의 「소속연구실」 국문 표기는 「운영체제 연구실」이다. 카이스트 스토리지 연구센터와 연구실은 별개 이름으로 구분했다. 머리의 직위는 학부 표기 「교수」를 따르며, People과 교수 소개의 ICT Endowed Chair Professor는 칭호다.

교수 경력의 2019.3–present와 학부의 2019년 부임 설명을 대조했다. LODIC 원문은 2021년 7월 발표 당시 원유집 교수의 소속을 KAIST로 적는다. 최근 논문 대상 구간은 KAIST 부임 뒤이며, 더 오래된 개인 경력·과제·수상을 현재 연구실 성과 목록에 합치지 않았다.

학부 교수 소개는 교수 위치를 IT융합빌딩 N1 309호로, 연구실 첫 화면은 연구실 위치를 같은 건물 313호로 적으므로 본문에 각각 표시했다. 교수 연락처는 원문의 7456을 그대로 싣고 전체 전화번호로 확장하지 않았다.

이메일 수집 거부 문구는 첫 화면, People, Research, Publications, 학부 교수 목록 2쪽, 학부 교수 소개, 교수 개인 소개, GAZE 소식, 오석준 참석 후기, 언론 기고·보도 목록, News 제목 쪽, Gallery 제목 쪽에서 각각 확인했으며 이들 화면 글에는 「수집」과 「거부」를 함께 담은 문장이 없었다. 교수 이메일은 학부 교수 소개에 문자로 공개된 기관 주소를 실었다. 연구실 첫 화면의 그림형 이메일을 본문 근거로 삼지 않았다. 두 논문 원문의 화면 글에도 이메일 수집 거부 문구가 없었으며, 그 안의 학생 이메일은 본문에 옮기지 않았다.

## 대표 논문 선정과 설명의 범위

대표 논문 8편의 전체 초록은 모두 OpenAlex 등록 초록이다. DOI, 제목, 발표처, 전체 저자 목록을 연구실 게시 항목과 대조했다. 여덟 편 모두 원유집 교수가 마지막 저자이며, 교신저자나 공동 기여자로 추정하지 않았다. 논문별 선정 이유는 다음과 같다.

| 번호 | 논문 | 선정 이유 |
|---|---|---|
| 1 | GAZE: Rearchitecting Log-Structured Filesystem for Garbage Collection on Zoned Namespace Flash Storage | 구역 단위 플래시 저장장치의 공간 회수 구조를 다루는 최신 논문 |
| 2 | Manycore Scalable Logging for Log-Structured Filesystem | 여러 실행 흐름이 쓰는 블록 할당 경로의 병목을 다룸 |
| 3 | lwFSCK: Light-weight Filesystem Check | 파일시스템 검사와 복구에 필요한 시간·메모리 문제를 다룸 |
| 4 | Fair I/O scheduler for alleviating read/write interference by forced unit access in flash memory | 읽기와 특정 쓰기 요청 사이의 공정한 자원 배분을 다룸 |
| 5 | LeaST: Learned Sector Translation for Skipped Physical Page Address | 불량 저장 영역이 학습 기반 주소 예측에 만드는 문제를 다룸 |
| 6 | Aker: Density-Aware Approximate Caching for Vector Search | 유사도 검색의 근사 캐시와 갱신 일관성을 함께 다룸 |
| 7 | Key-Space Partitioned LSM Tree for CMM-H | 키 공간 분할로 키·값 저장소의 쓰기 정지를 다룸 |
| 8 | SeeSSD: Computational Storage for Energy-Efficient Real-Time Object Detection | 물체 검출을 저장장치 안에서 수행하는 계산 저장장치 설계를 다룸 |

같은 연구 갈래에서 공간 회수와 검사, 여러 실행 흐름과 공정성, 주소 변환, 검색 구조, 계산 저장장치를 나누어 골랐다. 최신 논문만으로 채우지 않고 2022년과 2024년 사례도 포함했다. GAZE 등록 초록의 마지막 지연시간 수식은 의미가 분명하지 않아 그 수치를 설명에 쓰지 않았다. SeeSSD 등록 초록의 정확도 지표 표기와 전력 감소 배율은 요약에 옮기지 않고 방법과 방향만 설명했다. 대표 논문 설명에 논문 본문에서 읽은 성능 수치나 원문 초록에 없는 논문 사이의 관계를 덧붙이지 않았다.

대표 논문 참여 표시는 Juwon Kim, Jieun Kim, Dohyun Kim, Seung Won Yoo, Sukjoon Oh, Hwanseok Yoo, Minki Kang의 7명에게 붙었다. 철자와 이름 순서가 같은 전체 저자 이름만 사용했다. 졸업생 표의 성·이름 순서나 한글 표기를 뒤집어 새로운 이름 대응을 만들지 않았다.

## 태그와 용어 설명

「컴퓨터 구조·운영체제」는 운영체제 내부 동작과 여러 계산 환경의 성능을 연구한다는 Research 설명 및 교수의 현재 관심 분야에 근거한다. 「저장 시스템·SSD」는 플래시 저장장치용 파일시스템, 비휘발성 메모리를 다루는 소프트웨어와 저장장치 제어 계층을 개발한다는 같은 설명에 근거한다. 연구 소개에서 이름만 열거한 다른 갈래와 개별 공동 연구의 응용을 독립 태그로 넓히지 않았다. 본문의 두 도입 절에서 기술 용어를 첫 등장에 괄호나 같은 문장의 뜻 설명으로 풀었으므로 같은 낱말에 중복하는 마우스 올림 풀이는 붙이지 않았다.

## 읽지 않은 자료

OPIMQ의 학회 논문 페이지는 읽지 않았다. Courseware, Open Source, Members Only, Join Us는 연구 설명이나 성과 목록의 근거로 쓰지 않았다. 언론 기고·보도 목록의 개별 글은 읽지 않았다. Gallery 메뉴 쪽의 개별 글 목록은 읽지 않았으나, 글 목록 피드의 Gallery 분류 5건은 위 분류 범위에 포함했다.
