## 대표 논문을 고른 이유

네 갈래에서 2·2·2·1편을 골랐다. 대표 논문마다 학회 페이지의 전체 저자 목록에서 Sukyoung Ryu와 KAIST 소속을 확인했다. 여섯 편에서 마지막 저자이며, 실행 기록을 이용한 축소 논문에서는 다섯 명 중 네 번째다. 교신·책임저자 여부는 저자 순서만으로 정하지 않았다.

1. JEST: N+1-version Differential Testing of Both JavaScript Engines and Specification (2021): 언어 명세와 여러 구현을 함께 시험하는 초기 성과다. 초록 출처는 해당 학회 아카이브다.

2. Failing with Purpose: Dangling Coverage-Guided Negative Test Generation from a Mechanized P4 Type System (2026): 기계가 읽는 타입 규칙에서 거부해야 할 프로그램을 만드는 최신 성과다. 초록 출처는 해당 학회 아카이브다.

3. WEST: Specification-Based Test Generation for WebAssembly (2025): 언어 명세에서 시험 프로그램을 자동 생성하는 연구이며 수상 논문이다. 초록 출처는 해당 학회 아카이브다.

4. Execution-Aware Program Reduction for WebAssembly via Record and Replay (2025): 실행 기록과 재생으로 오류 재현 프로그램을 축소한다. 초록 출처는 해당 학회 아카이브다.

5. Concrat: An Automatic C-to-Rust Lock API Translator for Concurrent  Programs (2023): 동시 실행 프로그램의 잠금 사용을 Rust 방식으로 바꾼다. 초록 출처는 해당 학회 아카이브다.

6. Forcrat: Automatic I/O API Translation from C to Rust via Origin and Capability Analysis (2025): 입출력 함수와 오류 처리의 차이를 정적 분석으로 다룬다. 초록 출처는 해당 학회 아카이브다.

7. Exact Inference for Quantum Circuits: A Testing Oracle for Quantum Software Stacks (2025): 양자 회로 결과 분포를 계산해 양자 소프트웨어를 시험하는 기준을 만든다. 초록 출처는 해당 학회 아카이브다.

## 확인한 범위와 확인하지 못한 점

- 활성 여부: 구성원 명단에 박사후연구원과 재학생이 있고, 2025년 학회 초록 페이지가 류석영과 구성원들의 KAIST 소속을 밝힌다. 2026년 리더연구 선정 소식도 연구 활동의 근거다.
- 구성원: 교수는 별도 소개하고 명단의 박사후연구원 1명, 석박사통합과정 2명, 박사과정 5명, 석사과정 5명을 실었다. 윤동준·김경원·심유성의 개인 소개에 적힌 시작과 연구 관심을 더했다. 윤동준의 시작은 학위과정 시작이므로 본문 표의 과정 시작 칸에 구분했다.
- 졸업생: Alumni 28명 중 2021–2026년 11명을 실었다. 연도는 학위 취득 연도이며 개별 월·일은 명단에 적혀 있지 않다. 그 이전 17명은 최근 졸업생 표에 싣지 않았다.
- 논문 목록: 2021–2026년 구역의 원문은 44항목이다. 연도별로 2026년 10, 2025년 10, 2024년 9, 2023년 7, 2022년 2, 2021년 6항목이다. 교수 비저자 3항목과 강연·튜토리얼 6항목을 구분해 최근 논문은 35편으로 두고, 심유성 개인 소개의 국내 논문 3편을 더해 38편을 실었다. 국내 학회 발표와 같은 제목의 2024년 학술지 논문은 발표처가 다른 별도 항목으로 두었다.
- 교수 비저자 3항목은 「Automated Code Transformation for Distributed Training of TensorFlow Deep Learning Models」(2025), 「Improving Automatic C-to-Rust Translation with Static Analysis」(2023), 「JavaScript Static Analysis with Evolving Engines and Specification」(2021)다. 각 원문이 전체 저자 목록에 교수를 적지 않아 최근 목록에서 제외했다.
- 강연·튜토리얼 6항목은 교수와 전문 분야에 주제·행사·연도를 적었다. 2020년·Before 2020의 논문, Refereed Chapters in Books의 2009년 항목 1건, Refereed Articles의 2007·2008년 항목 2건, Technical Reports의 2011·2013년 항목 7건은 최근 목록에 싣지 않았다. Material 페이지의 연구 자료·기술 보고서·시연 자료 링크는 문서나 영상을 읽지 않았다.
- 수록 시기: 논문은 연구실의 2021–2026년 구역을 썼다. 2026년 10월 논문은 월만으로 기준일 이후라 단정하지 않았고, to appear 1편은 게재 예정으로 구분했다. JEST의 2021년 5월 논문은 논문 연도 구역 기준으로 싣되 그 논문상은 수상 기간보다 앞서므로 수상 목록에는 싣지 않았다.
- 과제: 2026-05-28 발표의 리더연구 유형A 선정 1건이다. 지원 시작은 기사에서 2026-06-01로 안내하지만 개별 과제명·최종 수행 기간·배정 연구비를 확정하지 않았으므로 선정 사실과 분야만 실었다. PLDI 2024 공동 보도의 지원기관 목록을 개별 연구실의 별도 과제로 만들지 않았다.
- 특허: 읽은 연구실 소개·논문·소프트웨어·자료 메뉴에서 최근 특허를 확정하지 못해 특허 절을 두지 않았다.
- 수상: 2025년 5월 교육상과 2025년 11월 WEST 논문상 2건이다. 교육상은 당일 발표문의 「수상한다」라는 예정형을 보존해 수상자로 발표됐다고 적었다. 소식은 2024-07-03 KAIST 연구 보도 1건이며, 교수 외 연구팀의 논문을 이 연구실 성과로 옮기지 않았다.
- 읽지 않은 자료: PLDI 2024의 출력 매개변수 변환 논문 초록 페이지, PLDI 2023의 기능별 시험 범위 논문 초록 페이지, KAIST의 2025-06-18 PLDI 소식 상세 페이지는 읽지 않았다. 해당 논문들은 연구실 목록에 게시된 서지만 최근 논문 목록에 실었다.
- 이메일: 구성원 명단·교수와 세 개인 소개의 이메일은 기호형이라 본문에 싣지 않았다. 학과 교수진 원본의 이메일도 스크립트로 표시되므로 풀지 않았다. 연구실 첫 화면 원본과 읽은 페이지에서 이메일 무단 수집 거부 문장을 확인하지 못했으며, 이 판단과 관계없이 기호형·스크립트형 주소를 본문에 적지 않았다.
- 태그: 태그 어휘 1.8판(2026-10-28)을 썼다. 프로그램 분석·검증은 연구실 소개와 타입 검사·잠금 변환 연구, 퍼징은 P4 타입 규칙에 맞는 프로그램을 변형해 거부해야 할 입력을 만드는 퍼저 개발, 양자 컴퓨팅은 양자 회로의 결과 분포를 계산하고 물리적 일치를 증명하는 연구가 근거다.
- 대표 논문의 요약은 학회 게시 초록의 방법·결과에 한정했다. WEST의 오류 18건·다섯 실행기·확인 및 수정 10건, QASMInfer의 여섯 소프트웨어·오류 20건·비중단 오류 15건은 각 학회 게시 초록의 수치다. 출판사 최종판과의 수치 일치를 뜻하지 않는다.
