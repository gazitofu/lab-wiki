# Digital Heritage Lab

문화유산을 3차원으로 기록·분석하고 박물관 경험에 디지털 기술을 적용하는 연구를 소개한다. 이번 자료는 공식 명단·교수 프로필·메타버스 참여사이트를 대조한 부분 소개다. 랩 홈페이지 자체 본문과 전체 성과는 미확인이다.

| 항목 | 공식 공개 표기와 확인 범위 |
|---|---|
| 연구실 | Digital Heritage Lab |
| 지도교수 | 안재홍 |
| 명단 연결 | KAIST 문화기술대학원·메타버스대학원에 같은 지도교수와 연구실명이 게시됨 |
| 직위 | 문화기술대학원 교수 프로필의 초빙교수 표기. 메타버스 참여사이트의 일반 역할 Professor와 구분 |
| 홈페이지 | [공식 연결 주소](https://dhlab.kaist.ac.kr/). 이번 웹 도구에서 접근하지 못함 |
| 연구 주제 | 문화유산의 3차원 디지털 기록·분석과 디지털 박물관 기술 |
| 교수 호실 | 문화기술대학원 프로필의 N25동 3228호. 랩 전체 소재지로 확대하지 않음 |

## 공식 연결과 시점

[메타버스대학원 명단](https://meta.kaist.ac.kr/labs/)과 [문화기술대학원 명단](https://ct.kaist.ac.kr/boards/lists/lab_board)은 안재홍과 Digital Heritage Lab을 연결한다. [문화기술대학원 교수 프로필](https://ct.kaist.ac.kr/boards/view/faculty_board/118)은 초빙교수와 랩 홈페이지를 게시하고, 2016년 11월부터의 경력을 현재까지로 표시한다. 이는 페이지의 경력 표기이며 실제 재직을 별도로 검증한 결과는 아니다.

[메타버스 참여자 프로필](https://meta.kaist.ac.kr/members/11)은 소속을 문화기술대학원, 역할을 Professor, 상태를 Active로 표시하고 [랩 상세](https://meta.kaist.ac.kr/labs/dh-lab)로 연결한다. 이 프로필의 Entrance Date 2022-07-01은 구체적 의미가 미확인인 사이트 날짜 필드이며 KAIST 최초 임용일이나 정교수 직급의 근거로 해석하지 않는다. 영문 역할의 일반 표기와 문화기술대학원의 구체 직위를 구분한다.

이번 열람에서 랩 루트와 www 주소는 웹 도구의 접근 실패를 반환했다. 실제 HTTP 상태나 사이트 폐쇄 여부를 확인한 것은 아니다. 위 공식 대체 페이지에서 확인한 명칭·연결·연구주제를 랩 홈페이지 자체의 본문 열람으로 표시하지 않는다.

## 기존 후보와 확인 상태

| 기존 후보 ID | 원래 명단 |
|---|---|
| `kaist:c:meta:lab-15` | 메타버스대학원 |
| `kaist:c:ct:lab-6` | 문화기술대학원 |

기존 두 후보의 공식 교차명단 연결 근거를 보강한 자료다. ID 병합·영구 ID 승격·원수집 필드 자동채택은 적용하지 않았다. 표의 행수는 고유 연구실 수가 아니다.

| 항목 | 상태·범위 | 남은 확인 |
|---|---|---|
| 명칭 | verified / partial | 랩 자체 본문과 갱신시점 |
| 소속·명단 관계 | verified / partial | 정식 임용·참여 형태와 기간 |
| PI | verified / partial | 실제 재직·직위 유효 시점 |
| 공개 구성원 | verified / selected-list | 참여사이트 밖 전체 구성원·명단 갱신일·실재직 |
| 연구 주제 | verified / partial | 랩 홈페이지의 상세 연구 |
| 논문·학술발표 | not-collected / unknown | 게시 항목의 정확한 날짜·DOI·당시 소속·랩 연결 |
| 과제 | not-collected / unknown | 과제 식별자·기간·기관·지원 주체 |
| 연구 이력 | not-collected / unknown | 날짜가 있는 기술·연구 변화 |
| 뉴스·활동 | not-collected / unknown | 공식 원문·사건일 |
| 특허·사업화 | not-collected / unknown | 공개 원부·이전·창업 근거 |

랩 상세에는 성과 항목이 게시되어 있으나 일부 날짜·발표처가 부족하고, 한 항목은 표시 저자와 이 연구실의 연결이 미확인이다. 게시 위치만으로 랩의 확정 성과로 채택하지 않았다. 상세 미수집은 성과나 과제가 없다는 뜻이 아니다.

열람일은 2026-10-16이다. 첫 성과 수집 이력창 2021-10-13–2026-10-13과 구분하며 현재 명단으로 과거 소속을 소급 확정하지 않는다. 기관 전수·전체 성과·실재직은 미검증이다.

공식 연결·자료구조·공개 경계의 고정 범위 독립 검토를 통과했으며 실재직·성과·임용과 접근의 미검증은 유지한다.
