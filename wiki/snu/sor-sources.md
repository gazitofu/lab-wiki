## 이름·직급·위치 표기 차이

학과는 ‘보안 최적화 연구실’, ‘Security Optimization Research (SOR) Lab.’으로 적고 지도교수로 백윤흥 교수를 연결한다. 누리집 바닥글은 ‘SOR Lab.’이며 사이트 틀의 제목은 ‘서울대학교연구원’이다. 본문 제목과 지도교수는 학과 표기를 기준으로 했다.

Introduction은 백윤흥·이병영 교수가 이끄는 Security Hardware and Software Design Group을 소개하고 Professors도 두 교수를 함께 싣는다. Privacy Enhancing Computing·AI Computing의 담당 교수는 백윤흥, System Security는 백윤흥·이병영을 표기한다. 이 문서는 학과가 보안 최적화 연구실에 연결한 백윤흥 교수를 대상으로 했다. 별도의 이병영 교수 연구실과 합치거나 두 교수의 실적 전체를 하나의 랩 실적으로 취급하지 않았다.

백윤흥 교수의 서울대 부임은 학과 소개의 2003년 3월 부교수 임용과 개인 소개의 2003년 봄 부임을 함께 확인했다. 정교수 시점은 학과의 2007년 10월과 개인 소개의 2007년 가을이다. 이전 소속은 NJIT와 KAIST다. 현재 학과명은 전기·정보공학부이며 경력란의 당시 ‘전기.컴퓨터공학부’와 구분했다. Paek, Yunheung과 논문의 Yunheung Paek은 서울대 소속·경력·공저자 연결로 대응시켰다. 일부 게시물의 Yunheung Peak 표기는 그대로 두었다.

## 대표 논문을 고른 이유

암호 계산·암호 하드웨어, 프로그램·차량 보호, 인공지능 공격·방어, 인공지능 가속기 설계에서 두 편씩 골랐다. 모두 2003년 서울대 부임 이후의 연구이며 전체 저자 순서에 백윤흥 교수가 있다.

1. SLOTHE : Lazy Approximation of Non-Arithmetic Neural Network Functions over Encrypted Data: 비산술 함수의 코드를 나누어 필요한 부분만 근사하는 암호화 계산.
2. SPHINCSLET: An Area-Efficient Accelerator for the Full SPHINCS+ Digital Signature Algorithm: 양자내성 디지털서명 전체를 처리하는 암호 하드웨어.
3. TRust: A Compilation Framework for In-process Isolation to Protect Safe Rust against Untrusted Code: 안전한 Rust 자료와 신뢰하지 않는 코드의 메모리 분리.
4. SECV: Securing Connected Vehicles with Hardware Trust Anchors: 하드웨어에 기반한 차량 제어 메시지 검증과 최신 연구.
5. VFLIP: A Backdoor Defense for Vertical Federated Learning via Identification and Purification: 수직 연합학습의 백도어 탐지와 정화.
6. FLGuard: Byzantine-Robust Federated Learning via Ensemble of Contrastive Models: 악성 참여자의 학습 갱신 탐지.
7. Modeling and Library Support for Early-Stage Exploration of Sparse Tensor Accelerator Designs: 희소 텐서 가속기의 설계 요소를 모델링하고 설계 탐색을 지원.
8. Towards an efficient dataflow-flexible accelerator by finding optimal dataflows of DNNs: 신경망 층에 맞춰 자료 흐름 모드를 고르는 가속기 설계.

초록 출처는 USENIX 논문집 2편, NDSS 학회 아카이브 1편, arXiv 2편, Crossref 등록 초록 1편, OpenAlex 등록 초록 2편이다. 등록 초록을 출판사·학회 게시 초록으로 부르지 않았다. Crossref 등록 서지는 저자 순서를 대조하는 데 썼다. 등록 초록·서지에서 확인하지 못한 권·호·쪽과 상세 날짜를 보충하지 않았다.

VFLIP·FLGuard의 arXiv 게시 연도는 2024년이고 각 페이지는 ESORICS 2024·ESORICS 2023 채택 논문으로 적는다. 대표 표는 설명에 사용한 공개판 연도를 쓰고 일반 목록은 누리집의 학회 연도를 보존했다. 학회판의 권·쪽·출판일을 공개판 정보로 보충하지 않았다.
